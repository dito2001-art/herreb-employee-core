# HerreB AI Workforce — Progress Reporting Rules

Permanent project operating rule:

1. Every progress update must include a status list.
2. The list must explicitly separate **DONE** from **TO DO**.
3. Each major workstream must include a completion percentage.
4. Always include one overall project completion percentage.
5. Percentages only increase when supported by implemented and/or verified evidence; do not inflate progress.
6. Work autonomously in large blocks. Do not stop for intermediate confirmations when the next action is already authorized and safe.
7. Ask the owner only for actions that genuinely require owner credentials, external account interaction, permissions, or a business decision.
8. Validate before declaring a block complete; production/main changes require the applicable CI/E2E evidence.
9. Initial AI Employee catalog remains EMP-001, EMP-002 and EMP-003. Do not create EMP-004 until the initial three operate in HerreB (Client 0), are multi-tenant, and demonstrate value in 2–3 pilots.
